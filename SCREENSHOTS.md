# DevTools Desktop — Screenshot Plan

Recommended screenshots to capture for the store listing and marketing materials.

---

## Screenshot 1: Dashboard / Tool Collection (Dark Theme)

- **Screen:** Main application window with the sidebar visible and JSON tool active.
- **What should be visible:** Full application window showing the sidebar with all 10 tools listed, the JSON Formatter workspace with sample formatted JSON, and the dark theme active.
- **Sample data:** Use a realistic JSON payload such as a mock API response with nested objects (e.g., a user profile with name, email, address, and preferences).
- **Feature demonstrated:** The complete application layout, professional dark UI, all 10 tools in the sidebar.
- **Caption:** "10 developer tools in one clean, dark-themed interface."

## Screenshot 2: JSON Formatter in Action

- **Screen:** JSON Formatter tool with formatted output visible.
- **What should be visible:** Input panel with minified/messy JSON on the left, beautifully formatted output on the right, and the Format/Minify/Validate buttons.
- **Sample data:** A moderately complex JSON object (15–25 lines when formatted) such as a product catalog entry with nested arrays.
- **Feature demonstrated:** JSON formatting with clear, readable output.
- **Caption:** "Format, minify, and validate JSON instantly."

- **Screen:** HTTP Client tool after a successful GET request.

- **Feature demonstrated:** API testing capability with response inspection.
- **Caption:** "Send API requests and inspect responses — right from your desktop."

## Screenshot 7: JWT Decoder

- **Screen:** JWT Decoder tool with a decoded token displayed.
- **What should be visible:** A JWT string in the input, decoded Header section showing algorithm/type, and decoded Payload section showing claims (sub, name, iat, exp).
- **Sample data:** Use a standard example JWT from jwt.io (the public example token). Make sure it contains recognizable claims.

## General Tips

- **Resolution:** Capture at your monitor's native resolution. Minimum 1920×1080.
- **Window size:** Make sure the application window fills most of the screen but is not maximized (shows the Windows title bar and rounded corners for a polished look).
- **Clean desktop:** Hide or clean up desktop icons and taskbar before capturing.
- **Order:** Use Screenshots 1 and 3 as the primary/hero images. They communicate the most value at a glance.
- **Format:** Save as PNG for maximum quality.
