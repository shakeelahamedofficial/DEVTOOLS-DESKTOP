# Changelog

All notable changes to DevTools Desktop will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-26

### Added
- Initial commercial release of DevTools Desktop.
- JSON Tool: Format, minify, validate, load, and save.
- JWT Tool: Decode header and payload (no signature verification).
- Base64 Tool: Encode/decode text and files.
- URL Tool: Encode and decode URL strings.
- UUID Tool: Batch generate v4 UUIDs, export to TXT/CSV.
- Hash Tool: Generate MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512 hashes for text and files.
- Timestamp Tool: Convert Unix seconds, milliseconds, and datetime strings.
- Regex Tool: Test patterns with match highlighting and group extraction.
- SQL Tool: Basic SQL formatting and minification.
- HTTP Tool: Asynchronous HTTP client with custom headers support.
- Global Command Palette (`Ctrl+K`).
- Local Settings Management and usage history tracking.
- System, Dark, and Light themes.
